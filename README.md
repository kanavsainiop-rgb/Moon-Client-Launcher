# Moon-Client-Launcher
🌙 A free, performance-focused Fabric client mod - 65+ bundled optimization &amp; QoL mods, a custom HUD, mod menu, and night-sky UI. Supports Minecraft 1.20.1–1.21.11 (Fabric API, Java 17+). Pairs with a launcher that auto-installs, auto-updates, and ships  one-click performance mod packs.
